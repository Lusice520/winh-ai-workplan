# ADR-004：P1 文件存储、检索与受控分享

> 状态：已接受  
> 日期：2026-08-26  
> 决策人：项目负责人  
> 关联需求：PRD V0.4 的项目资料、版本、受控下载、外网链接＋密码分享、合同归档和 P3 NAS 演进  
> 关联验证：文件上传下载、版本替代、权限撤销、分享失效、限流、日志、备份恢复和容量验证

## 背景与问题

P1 需要在线保存项目资料、版本、当前有效状态和受控分享；P3 才执行 NAS 自动归档。文件二进制不能放入业务数据库，也不能让调用方获得底层路径或永久存储凭据。员工主系统仅经 VPN 访问，而分享链接按 PRD 需要面向外部访问者。

## 决策驱动因素

- 文件版本、业务关联、权限、分享和审计必须可追溯；
- 二进制文件要与关系型元数据分离；
- 外网分享不能暴露项目空间、主系统或对象存储；
- NAS 不应阻塞 P1。

## 候选方案

### 方案 A：S3 兼容对象存储与关系型文件元数据

文件记录、版本、关联、权限和分享元数据保存在 PostgreSQL；二进制保存在私有 S3 兼容对象存储，私有部署优先采用 MinIO。应用通过受控 Adapter 访问对象存储。

### 方案 B：应用服务器本地文件系统

早期简单，但不利于容器部署、备份、扩缩、短时下载授权和后续归档，不作为 P1 基线。

### 方案 C：NAS 直接作为过程资料库

与 PRD 的“系统作为过程协作入口、NAS 只做长期归档副本”冲突，不采用。

## 验证证据

- PRD 已确认文件版本、独立分享权限、链接密码、有效期、撤销和访问日志；
- NAS 自动归档被明确放在 P3；
- 已确认私有部署和员工 VPN 访问，需要把外网分享与主系统隔离。

## 决策

- P1 使用 PostgreSQL 保存文件记录、版本、关联、密级、校验值、分享和审计元数据；
- P1 使用 S3 兼容对象存储保存文件二进制；私有部署默认优先 MinIO，实际产品版本和许可证须在实施前完成 IT/安全审查；
- 下载和预览只能经文件权限判断和短时授权结果进行，不返回底层路径或永久凭据；
- P1 检索先使用 PostgreSQL 的受权限约束查询和元数据检索；独立搜索引擎仅在容量或质量证据出现后评估；
- 文件外网分享只能通过 ADR-007 定义的隔离公网入口处理，且每次访问都解析实际文件版本并记录日志；
- 文件大小、总量、病毒扫描、预览转换、水印和下载策略是上线前条件，不在本 ADR 中假定已经具备；
- NAS 接入不在 P1 实现，P3 前由 ADR-008 记录服务账号、网络、校验和恢复策略。

## 后果

### 正向后果

- 文件元数据与二进制生命周期独立，便于版本、审计、备份和未来 NAS 归档；
- 主系统不因分享需求开放公网；
- 对象存储实现可在保留 S3 语义的前提下替换。

### 负向后果与控制

- 对象存储、数据库和分享网关需要一致的备份与恢复验证；
- 文件扫描、预览和大文件能力没有自动获得，必须按真实样本决定；
- 公网分享是额外攻击面，未满足隔离入口、安全策略和日志要求时不得上线。

## 迁移与回退

对象键、校验值和版本关系由文件模块管理，不写入调用方业务表。更换对象存储时，以清单和校验值迁移并双读校验；回退不得丢失已发布文件版本或分享撤销状态。

## 复审触发条件

- 文件容量、预览或检索质量无法满足验证指标；
- IT/安全无法批准 MinIO 或外网分享入口；
- P3 NAS 归档要求改变在线文件模型；
- 需要引入独立搜索、扫描或内容处理平台。
