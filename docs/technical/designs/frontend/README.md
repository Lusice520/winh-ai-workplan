# 前端共享设计

本目录存放会被多个功能复用的前端工程与界面规范，包括脚手架、组件库、设计令牌、路由、状态管理、表单、表格、反馈、响应式和测试约定。

单一功能页面的字段、状态、文案、接口和实现设计仍以对应 SPEC 为准；真实 React 组件代码进入 `apps/web/`，不放在 docs 中。本目录不按功能创建 DES，只记录跨页面复用的约束。
