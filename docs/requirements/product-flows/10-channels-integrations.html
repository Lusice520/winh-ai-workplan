需求方案 10｜WEB、移动端、通知与系统集成

新系统保存客户、商机、项目状态和业务结果；飞书只做提醒，原商机表通过 Excel 一次性迁移后停用。

一、一个业务后台，三个使用入口
统一业务与权限底座
同一组织账号、工作台、项目、文件版本和审计记录
→
桌面WEB
规划、分析、资料、配置
移动端
任务、现场、审批、拍照
飞书入口（可选）
提醒、待办摘要、深度链接
不进入 P1 必验范围
二、桌面WEB与移动端的职责分工
桌面WEB｜复杂管理与集中操作
主计划 / 甘特图
工作包与资源排期
预算与采购分析
知识库与版本评审
项目 / 部门 / 公司看板
流程模板与权限配置
移动端｜现场执行与快速反馈
今日任务 / 日报
工时与位置状态
问题 / 风险 / 隐患
拍照、视频和语音备注
安全检查 / 培训确认
确认、评审和待办
三、P1 先形成站内闭环｜飞书只做后续提醒
系统事件
到期、评审、问题升级、阶段门、成员变更和经营节点
→
站内待办 / 消息
待办承接行动，消息告知变化
飞书可选发送摘要和深链
→
处理结果回到系统
更新正式状态、证据与审计记录
在飞书聊天中回复“已完成”不自动关闭系统任务；只有在新系统提交成果并通过验证才算正式完成。
四、数据与系统边界
新系统
客户、商机、主阶段/重点阶段/状态/结果、项目清单及当前有效资料的唯一事实源
飞书
消息、待办摘要和深度链接；不再维护正式商机表
Excel
一次性导入全部约 30—50 条历史与当前商机
NAS
验收后的不可变归档快照、清单、校验结果和档案位置
财务系统
未来可选对账/回写；不是 P4 项目管理口径台账的前提

Excel 只迁移当前行中的结构化字段，不迁移附件、评论和跟进历史；迁移完成后冻结飞书商机表，不建设双向同步。

五、数据任务与集成运行状态
数据任务中心
查看导入导出进度、成功/失败数量和结果文件
失败可恢复
下载错误明细，修正后重试，不重复覆盖成功数据
集成运行状态
查看连接、最近同步、失败原因和重试结果

P1 先交付 Excel 数据任务；飞书、NAS 和后续财务系统的连接管理随对应业务批次启用。凭证、网络和接口协议进入总体技术方案。

六、现场弱网候选策略｜不进入 P1
离线草稿
日报、问题和检查单可暂存
断点续传
照片和视频恢复网络后上传
离线模板
可提前下载当天任务与检查单
同步提示
明确未上传、冲突和完成状态

P1 不建设离线能力；进入 P3 现场交付后若真实网络条件需要，再从现场记录、问题、安全检查和媒体上传开始评估。

终端原则：P1 采用桌面 WEB＋移动响应式 WEB，不建设独立原生 APP；P3 若现场体验不足，再结合弱网、推送和设备能力重新评估。
