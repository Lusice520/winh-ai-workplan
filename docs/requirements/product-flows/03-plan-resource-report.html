需求方案 03｜阶段、计划、资源、报告与项目例会

P2 先建立阶段、里程碑、工作包、主计划、资源和预算基线；P3 再沿用基线记录任务、报告与例会事实。

P2/P3 边界：团队、执行阶段、项目清单、工作包、计划和预算草案在 P2 开始时开放，用于准备 DG-02；DG-02 通过后同一批对象转为已批准基线。P3 在该基线下开放任务、执行事实、日报周报和例会。售前的调研、方案、估算和招投标属于并行规定动作，不是这里的专业工作包。
