## 可重复验证

本地服务启动后运行 `./scripts/development/local-runtime.sh -- node scripts/development/business-flow-check.mjs`。此脚本会创建带验证标识的账号和业务记录，不删除已有数据，不是启动初始化逻辑。它只接受本机服务地址。临时口令留在进程中，浏览器会话仅写入被忽略的 `.local-data/`，不得提交或复制至交付报告。

使用 `BUSINESS_CHECK_ORIGIN` 和 `BUSINESS_CHECK_ARTIFACT_DIR` 可切换到独立本地验收服务。2026-09-12 已在空库 `winh_wi008_fresh_20260912` 从 V1 完整执行至 V6，服务监听 8081，再运行同一套检查；未重建或清空原 `winh_workplan`。
