## 7. 验收标准

- [x] 客户可创建、编辑、维护联系人、识别重复并受控合并，关系和历史不丢失。
- [x] 商机等级/进展/状态/结果独立；行动有责任人和日期；同一商机只能创建一个空间。
- [x] SG-01 批准前不得登记实际投入；规定动作可并行重开；成果版本历史可查；SG-02 显式复核且不可替代合同事实。
- [x] 原需求永久保留；评估、人工处理关系、完成证据与独立验证闭环；处理人不能自行关闭，基线影响必须关联正式变更。
- [x] 列表、详情、选择器及摘要遵守服务端数据范围；直接调用 API 无法越权；关闭项目只读。
- [x] 写入支持字段错误、并发冲突及安全重试，刷新和重启后数据仍可读。
- [x] 真实浏览器完成关键操作，390px 无页面级横向溢出，关键控件可键盘操作。

## 8. 验证计划

Maven 业务/HTTP 测试、前端类型/Lint/格式/Vitest/生产构建；独立 PostgreSQL 数据库上从空库执行全部迁移；隔离合成账号浏览器执行客户 → 商机 → 空间 → 立项 → 需求 → 处理 → 验证关闭；另一个无权限账号复核 API 拒绝。最终证据写入 TC-008 和 accept。

金融业务记录不自动产生银行付款或财务记账；公司审批阈值未配置时不自动批准。API 权限与业务状态均由服务端检查。新增业务表可与旧应用并存，已应用迁移用后续前向迁移修正；禁止用删除旧库回退。全系统目标保持持续，未验证或未实现内容按实列出，不用界面入口替代功能验收。
