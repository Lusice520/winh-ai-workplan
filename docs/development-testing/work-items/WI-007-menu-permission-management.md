## 1. 目标与结果

2026-09-13 接续：在用户“完成整个系统”的持续本地授权下完成剩余验证，无需重复请求本地合成账号的角色调整许可。检查发现高敏感临时授权缺少实际复核、角色修改/撤销漏检原级别，本 WI 按 SPEC-IAM-02 4.1.1 修复；当前 Codex 单人串行维护 IAM、对应前端和 V10 起前向迁移。范围包含组织用户工作区的只读操作显示、共同 HTTP 错误映射，以及 IAM 写入按操作者和完整请求内容校验幂等。仅使用新建合成账号和角色验证，保留现有项目及用户内容，不提交或部署。

交付一个完整、可本地启动和可验证的菜单与权限管理功能，而不是角色标签、静态导航或前端显示控制。权限管理员能够维护稳定菜单资源与权限项目录，定义系统/项目/阶段角色、数据范围和临时授权；系统使用同一套服务端权限决策生成动态导航并保护实际业务接口。

交付完成后，IAM-01 的初始化系统管理员安全桥接将迁移为正式 `listNavigation(subject)` 与 `decide(subject, action, resourceContext)` 能力。用户管理不再承担角色分配或授权编辑职责。

## 2. 范围与非目标

### 本次范围

- 菜单管理：目录、菜单页和操作资源的树形注册、稳定资源编码、受控 `routeKey`/动作键、图标键、排序、状态、引用影响与变更审计；
- 权限项目录：菜单/操作、组织与记录数据范围、敏感字段、文件查看/下载/分享、系统配置动作的可授权资源；
- 角色与授权：系统角色、项目角色模板、阶段角色模板、角色状态、权限矩阵、数据范围和授权影响预览；
- 临时授权：受授人、最小资源/动作/范围、原因、开始结束时间、到期自动失效与撤销审计；
- 权限预览：按用户、业务对象和目标动作返回允许/拒绝及解释链；
- 后端 Menu & Authorization Module、前端菜单与权限工作区、服务端授权 Adapter、动态导航和原有 IAM-01 安全桥接迁移；
- PostgreSQL 前向迁移、API 契约、审计、模块/HTTP/浏览器测试和本地验收记录。

### 本次不做

- 不在本工作项中实现客户、项目、文件、资金等业务 Module 本身；它们只接入通用 `decide(...)` Interface；
- 不把项目成员关系或员工档案改造为系统角色；项目成员的实际分配入口由项目空间相关 SPEC 负责；
- 不实现 SSO、MFA、公司 VPN、生产部署、远程 GitLab 或 CI；
- 不物理删除已被角色、授权、审计或历史业务引用的资源、角色和授权记录；
- 不在 IAM-01 的用户管理页面加入角色选择、菜单设置或权限矩阵。

## 4. 前置条件与依赖

- 前置工作项：WI-006 的登录、组织、账号、会话与审计基础；在本地人工验证完成后，IAM-01 的初始化安全桥接可作为迁移起点；
- 业务事实：SPEC-IAM-02 v0.5（已达 `ready-for-implementation`）；共享契约：IAM Foundation Contract；
- 外部依赖：本地 PostgreSQL、有效的初始化系统管理员会话；
- 已冻结事实：角色/临时授权只提供正向 `ALLOW`，账号/资源/范围/状态/密级等硬约束拒绝优先；数据范围枚举、可下放边界、普通 7 天/高敏感 24 小时临时授权上限、受控导航键和无跨请求授权缓存均以 SPEC-IAM-02 v0.5 为准；
- 合并顺序：当前本地单人开发；未来多人并行前，数据库迁移、Security Adapter、AppShell 和共享 Interface 必须指定唯一负责人。

## 7. 验收标准

- [x] 管理员可维护目录、菜单页和操作资源；编码全局唯一、被引用资源不可物理删除、停用影响在保存前可见且保留审计。
- [x] 路由、图标和操作只可选择已注册的受控键；不存在任意 URL、静态菜单白名单或未实现页面的导航兜底。
- [x] 权限项目录可表达菜单/操作、数据范围、敏感字段、文件查看/下载/分享和配置动作；菜单可见不自动授予业务动作。
- [x] 系统、项目和阶段角色可分别定义、配置、启停并查看引用影响；用户/项目成员分配不再伪装在 IAM-01 用户表单中。
- [x] 权限矩阵能表达资源、动作、范围和条件；服务端拒绝超出操作者可下放范围或不兼容的授权组合。
- [x] 多个角色/临时授权只产生正向允许；账号、资源、范围、状态、密级和强制条件的拒绝优先且不可被覆盖。
- [x] 临时授权具备最小范围、原因和起止时间，到期自动失效，创建/撤销/到期均可审计。
- [x] 权限预览对指定主体、动作和资源上下文给出允许/拒绝及解释链，不泄露无权对象的数据。
- [x] AppShell 导航和服务端接口都消费同一授权决策；绕过前端直接调用接口会被服务端拒绝。
- [x] IAM-01 初始化系统管理员桥接已被正式授权能力替代；不存在长期并行的静态菜单或双授权规则。
- [x] 真实 PostgreSQL、Flyway、后端 Module/HTTP 测试、前端交互测试和浏览器验收均通过；运行时无 Mock 授权数组。

## 9. 风险与边界

- 本地验收不代表生产部署、安全渗透或全量性能验收；认证、目录与 IAM 权限决策均使用真实服务和 PostgreSQL。
- 权限项和受控能力随业务 Module 的前向迁移注册。审计中心检索、消息渠道和后续业务权限的接入随对应工作项完成。
- 临时授权/权限预览的账号候选仍取最多 100 条；系统角色授权页已改为服务端搜索分页。候选规模扩展列入后续共享候选选择任务，不能据此宣称大规模人员目录验收完成。
- 前端共享依赖包存在 500 kB 构建体积提示，尚未开展性能基准测试。
- 测试使用明确标注的合成账号/角色。早期验证发现根目录空父级比较造成一次无实际层级变化的移动审计事件；修正后只改名不再发起移动请求，原验证历史保留。
- 回退使用前向修复与正式角色/授权状态调整；不重新引入初始化直接放行、不删除授权和审计历史。

## 10. 完成交接

- V3/V4 构成菜单与角色基础，V10 补齐高敏感临时授权的申请人、待独立复核、实际复核人与意见，数据库保护三方独立。
