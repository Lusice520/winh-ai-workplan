## 1. 目标与结果

将已验证的组织与用户视觉原型替换为可本地启动、可持久化、可测试的真实登录与用户管理闭环：初始化管理员能够安全登录、维护组织/部门和用户、处理状态/调动/密码重置，所有写操作经过服务端会话、CSRF、并发/幂等与审计保护。

完成后，浏览器中的数据来自 PostgreSQL 和真实 API，不再来自 `mock-data.ts`；当前切片的安全桥接只允许初始化系统管理员管理 IAM-01，不假装实现角色或权限体系。

## 2. 范围与非目标

### 本次范围

- 本地 PostgreSQL 运行入口、环境模板、Flyway 和可重复启动验证；
- 身份会话、密码哈希、登录/登出/当前会话、首次改密、锁定与会话撤销；
- 组织/部门树、用户目录、用户详情、创建/编辑/调动、启停/锁定/离职/恢复、重置密码；
- 账号/组织状态历史与安全/管理审计；
- 前端真实登录页、路由守卫、HTTP 客户端、CSRF、问题响应、分页和组织用户工作区 API 集成；
- 后端 Module 行为测试、Flyway/HTTP 集成测试、前端交互测试与关键浏览器验收；
- 将现有 Mock 仅保留为测试 fixture 或视觉参考，并从运行时路径移除。

### 本次不做

- 不实现菜单管理、权限资源、角色、角色分配、数据范围、临时授权、权限预览或动态导航；它们由独立的 SPEC-IAM-02 / 后续工作项交付；
- 不实现用户批量导入、数据任务中心、SSO、MFA、生产部署、公司 GitLab、CI 或远程数据库；
- 不创建默认明文密码、不把真实密码、会话、数据库数据或密钥写入源码、文档、日志或截图；
- 不提交、推送、创建 Merge Request 或部署。

## 9. 风险与回退

- 已知风险：本机浏览器控制桥在重载后偶发丢失会话，且其刚打开抽屉时的自动化填值会与表单初始化重置竞争；本次已由项目负责人在真实浏览器填写临时密码并即时确认最终提交，不能再将该工具差异当作未完成产品验收；
- 已知风险：若 CSRF 再次失效，前端会清除旧令牌但不会自动重放写请求，避免重复创建；用户需直接再次点击提交。
- 已知风险：原型单文件包含大量 Mock 状态，迁移时需防止视觉修复与业务规则再次耦合；
- 回退方式：停止本地进程并保留数据目录；代码或 schema 出错用新的前向迁移修正，不删除账号、历史、会话撤销或审计事实；
- 未验证项：生产 HTTPS Cookie、公司 VPN、备份恢复、SSO/MFA 和 IAM-02 权限决策不在本工作项内。
