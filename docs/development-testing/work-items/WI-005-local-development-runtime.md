## 1. 目标与结果

让项目在当前 macOS 本机上不依赖系统级 Java 或全局 Node 版本即可完成前端、后端的启动与检查；运行时放在已忽略的 `.local-tools/`，而可重复执行的脚本与说明留在项目中。

## 2. 范围与非目标

### 本次范围

- 提供带校验的 Node 24.19.0 与 Java 21 本地运行时准备脚本；
- 提供统一的本地运行时包装脚本，并让根目录前后端命令使用它；
- 以真实启动、健康检查、前后端代理和全量骨架检查作为验收证据；
- 更新本地启动说明，明确本地优先、不以 Git 为当前阻塞条件。

### 本次不做

- 不引入 PostgreSQL、Flyway、Docker、MinIO 或任何外部业务依赖；
- 不实现登录、组织用户、权限、审计或其他业务能力；
- 不提交、推送、创建 Merge Request 或配置 GitLab；
- 不把 `.local-tools/` 中的运行时、环境变量、密钥或运行数据写入项目事实源。

## 9. 风险与回退

- 已知风险：首次下载依赖公网；下载中断或校验不通过时不会覆盖已有可用运行时；
- 控制方式：Node 与 Java 下载均使用官方来源和 SHA-256 校验；
- 回退方式：停止相应本地进程并删除明确的 `.local-tools/` 运行时目录即可，不影响业务代码或数据；
- 已知提示：前端生产构建仍有一个超过 500 kB 的 Lucide 相关 chunk 警告；它不阻塞本地启动，但正式 IAM 页面增加后需在相应实现工作项中处理拆包。
- 已知提示：后端测试会输出 Mockito 动态加载 Agent 的未来兼容警告；当前 2 个测试均通过，升级 Spring Boot 或 Mockito 时需按官方方案复核。
- 未验证项：PostgreSQL、Flyway 与正式 IAM 运行环境不在本工作项范围内。
