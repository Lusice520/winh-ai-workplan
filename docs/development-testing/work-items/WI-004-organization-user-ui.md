## 0. 定位修正（2026-08-27）

本工作项是已确认视觉方向的**交互式前端原型**，用于验证信息架构、表单模式、工作台壳层、浏览器交互和可访问性基础。它不构成 `SPEC-IAM-01` 的正式实现，也不能作为认证、授权、审计、接口、数据库迁移、并发控制或业务数据处理的验收证据。

后续正式 IAM 开发必须使用独立 work-item 和独立分支，在 `SPEC-IAM-01`、`SPEC-IAM-02` 及共享身份权限设计进入 `ready-for-implementation` 后实施。正式模块须提供可验证的数据所有权、公开 interface、前后端契约、数据库迁移、安全测试和端到端验收；不得将本工作项中的浏览器内 Mock 状态直接升级为生产实现。

## 1. 目标与结果

将已确认的浅色高密度工作台视觉落实为首个可运行的交互式前端原型：用户可在“组织与用户”工作区查看组织树和用户目录、筛选与搜索用户、打开用户详情，并使用符合页面设计的“新建用户”和“编辑部门”抽屉完成本地 Mock 数据下的主要操作闭环。

## 2. 范围与非目标

### 本次范围

- 将现有深色原型 AppShell 调整为已确认的白色左侧工作台壳层、紧凑顶栏和系统管理导航；
- 新增组织与用户工作区、组织树、用户目录、用户详情、新建用户与编辑部门的交互式前端页面；
- 提供受控的本地 Mock 数据、字段级校验、抽屉未保存状态提示和本地成功反馈；
- 实现普通字段“左标签 / 右控件、每行一个字段”与多行说明“标签在上 / 全宽输入”的统一表单模式；
- 为核心交互补充前端测试，并通过现有前端检查和浏览器视觉核对。

### 本次不做

- 不接入真实登录、会话、Spring Security、数据库、Flyway、组织/用户 API 或审计服务；
- 不实现用户批量导入、凭证重置、离职交接、真实权限计算或角色矩阵；
- 不实现角色、客户、商机、项目空间的正式页面；
- 不创建 Git 提交、推送、GitLab MR、部署或共享环境配置；
- 不复制参考图中的第三方品牌、业务数据或图标资产。

## 6. 实施步骤

1. 建立与选定设计一致的浅色工作台壳层、菜单层级、页签与顶部上下文；
2. 新建组织与用户功能模块，定义可读的组织、用户和状态 Mock 数据；
3. 实现组织树切换、用户目录筛选/搜索、详情与状态操作反馈；
4. 实现编辑部门与新建用户抽屉，落实单字段行与多行文本布局、校验和成功更新；
5. 补齐核心组件测试、响应式和键盘可达性检查；
6. 执行前端检查、浏览器交互验证与设计 QA，并回填本工作项结果。

- 回退方式：恢复本工作项涉及的前端文件即可回到原型壳层；不涉及数据或环境回退；
- 未验证项：公司真实 Logo、组织数据规模、辅助技术、浏览器版本、后端接口和安全策略。
